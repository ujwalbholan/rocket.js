# Changelog

All notable changes to Rocket.js are documented in this file.

## 1.0.0 - 2026-06-05

### Added

- Class-based `Rocket` application API.
- Controller and route annotations.
- Controller, service, and repository application structure.
- MiniHTTP and browser-readable HTTP request/response support.
- Byte-safe TCP framing and request safety limits.
- Text, JSON, empty, and custom-header responses.
- Ordered class-based middleware and centralized error mapping.
- Optional in-memory rate limiting.
- Observable server lifecycle with graceful shutdown.
- Runtime validation for requests, routes, and application errors.
- Duplicate route registration protection.
- Automated framework, lifecycle, and package-consumer tests.
